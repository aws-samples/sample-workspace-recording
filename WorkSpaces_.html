数据流说明
① session-start 以 SYSTEM 运行，下载运行时脚本与配置，并等待交互式会话就绪
② PsExec 将 record-agent.ps1 以 SYSTEM 身份送入会话桌面，ffmpeg 持续分段录制
③ 分段写完（静默 quietSeconds）→ 使用 fleet IAM 角色的命名 profile 加密上传到会话专属 S3 prefix，成功即删本地
④ 登出 / 实例回收前，session-stop 置停止标志，Agent 冲刷剩余分段并退出
⑤ S3 Event 触发 Lambda 建索引（可选），供审计检索
⑥ Object Lock + KMS + CloudTrail(S3 数据事件) 提供防篡改与调阅审计
⑦ 中心侧按 Agent 心跳做覆盖率巡检与断档告警
